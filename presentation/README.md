## 📥 How to Download the PowerPoint (.pptx) Presentation

The presentation is fully exportable as a native Microsoft PowerPoint (`.pptx`) file directly from the web application:

1. **In the Web App (`index.html`):**
   - Click the **"📥 Download PPT (.pptx)"** button located in the top navigation bar, on **Slide 1**, or in the **Presentation Deck** header.
   - The browser will compile and download `BrightWave_Retail_Promotion_Analytics_Presentation.pptx` right into your `Downloads` folder.
   - It is an authentic, 100% editable Microsoft PowerPoint file with real shapes, formatted tables, colored badges, and all metrics in **Rs.**.

2. **Export as PDF / Print Slides:**
   - Click the **"Export PDF / Print"** button in the Presentation Deck tab (or press `Ctrl + P`).
   - The web app is styled with custom `@media print` rules that format all 6 presentation slides into a landscape, one-slide-per-page PDF document.
